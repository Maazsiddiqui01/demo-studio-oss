Two modes

    
Real data stays private

    

      
Handover
The client's own system and real data. The video stays on your machine for that client.
mode: handover

      
Public
Demo or seeded data only. Names you list never reach the screen.
mode: public

What it is for

    
One storyboard, many videos

    

      
01
Client handovers
How the system you built works, on their own data.

      
02
Portfolio and website
Show the work with demo data.

      
03
Proposal clips
60 to 90 seconds, cut from the same file.

      
04
Onboarding
New users see each step once.

      
05
Release notes
Re-render when the app changes.

      
06
Square cuts
A variant for social feeds.
